# คำถามที่พบบ่อย (FAQ) — ระบบ RSAT

## 1. ระบบ RSAT คืออะไร?

RSAT (Road Safety Actions Tracking) คือระบบติดตามข้อเสนอแนวทางในการป้องกันและลดอุบัติเหตุทางถนน ซึ่งมติจากการประชุมคณะกรรมการนิรภัยทางถนนแห่งชาติในช่วงเทศกาลต่างๆ จะถูกบันทึกไว้ในระบบนี้ เพื่อให้หน่วยงานที่รับผิดชอบสามารถรายงานความคืบหน้าได้ และเลขาธิการคณะกรรมการฯ สามารถติดตามสถานะได้ในที่เดียว

## 2. หน่วยงานของเราจะเข้าสู่ระบบเพื่อกรอกรายงานได้อย่างไร?

ไปที่เมนู "เข้าสู่ระบบสำหรับหน่วยงาน" (ปุ่มมุมบนขวาของหน้าหลัก) แล้วใช้ username และ password ที่ได้รับจากเลขาธิการคณะกรรมการฯ

หากยังไม่เคยเปลี่ยน password ให้เปลี่ยน password เองได้เลยหลังจาก login ครั้งแรก เพื่อความปลอดภัยของข้อมูล

## 3. ลืม username หรือ password ต้องทำอย่างไร?

ติดต่อเลขาธิการคณะกรรมการฯ โดยตรง ผู้ดูแลระบบสามารถ reset password ให้ได้

สามารถส่งคำขอได้ผ่านหน้า "ขอรีเซ็ตรหัสผ่าน" ในหน้าเข้าสู่ระบบ หรือติดต่อทาง email/โทรศัพท์กับทีมเลขาธิการโดยตรง

## 4. แต่ละสถานะมีความหมายอย่างไร?

- ○ ยังไม่ดำเนินการ — รับทราบข้อเสนอแล้ว แต่ยังไม่ได้เริ่มดำเนินงาน
- ◑ กำลังดำเนินการ — อยู่ระหว่างดำเนินงาน มีความคืบหน้าบางส่วน
- ✓ เสร็จสิ้น — ดำเนินการครบถ้วนตามข้อเสนอแนะแล้ว
- – ไม่เกี่ยวข้อง — ข้อเสนอนี้ไม่อยู่ในขอบเขตภารกิจของหน่วยงาน

หากไม่แน่ใจว่าควรเลือกสถานะใด ให้เลือก "กำลังดำเนินการ" แล้วระบุรายละเอียดในช่องความคืบหน้า

## 5. ถ้าข้อเสนอนี้ไม่เกี่ยวข้องกับหน่วยงานของเราควรทำอย่างไร?

เลือกสถานะ "ไม่เกี่ยวข้อง" และสามารถใส่คำอธิบายสั้นๆ ได้ในช่องรายละเอียด เช่น "ไม่อยู่ในขอบเขตภารกิจของหน่วยงาน" หรือ "ส่งต่อให้หน่วยงาน ก." เป็นต้น

การเลือกสถานะนี้จะไม่นับรวมในการคำนวณเปอร์เซ็นต์ความคืบหน้าของข้อเสนอนั้น

## 6. กรอกรายงานแล้วแก้ไขได้หรือไม่?

ได้ หน่วยงานสามารถแก้ไขรายงานได้ตลอดเวลา ระบบจะบันทึกประวัติการแก้ไขทุกครั้งพร้อมวันเวลาที่อัปเดตล่าสุด

แนะนำให้อัปเดตรายงานให้เป็นปัจจุบันเสมอ โดยเฉพาะก่อนการประชุมคณะกรรมการฯ ในแต่ละวาระ

## 7. ต้องกรอกรายงานภายในกำหนดเวลาใด?

เลขาธิการคณะกรรมการฯ จะแจ้งกำหนดเวลาส่งรายงานผ่านระบบข้อความ (ส่วน "ข้อความจากแอดมิน" ในหน้าของหน่วยงาน) และทางช่องทางการสื่อสารอื่นๆ

โดยทั่วไปจะมีการรวบรวมข้อมูลก่อนการประชุมคณะกรรมการฯ ประมาณ 1–2 สัปดาห์

## 8. ข้อมูลที่หน่วยงานกรอกจะถูกนำไปใช้อย่างไร?

ข้อมูลจะถูกนำไปใช้ใน 3 ลักษณะ:

1. สรุปรายงานความคืบหน้านำเสนอต่อคณะกรรมการนิรภัยทางถนนแห่งชาติในการประชุมแต่ละวาระ
2. จัดทำรายงานภาพรวมสาธารณะ (เฉพาะสถานะและความคืบหน้า ไม่เปิดเผยข้อมูลผู้กรอก)
3. ใช้ในการวางแผนและติดตามการดำเนินงานของคณะอนุกรรมการแต่ละชุด

## 9. อนุกรรมการในระบบมีกี่ชุด และแต่ละชุดดูแลเรื่องอะไร?

ปัจจุบันมีคณะอนุกรรมการ 8 ชุด:

- อนุฯ 1 — ด้านการบริหารจัดการความปลอดภัยทางถนน
- อนุฯ 2 — ด้านถนนและการสัญจรอย่างปลอดภัย
- อนุฯ 3 — ด้านยานพาหนะปลอดภัย
- อนุฯ 4 — ด้านผู้ใช้รถใช้ถนนอย่างปลอดภัย
- อนุฯ 5 — ด้านการตอบสนองหลังเกิดอุบัติเหตุ
- อนุฯ 6 — ด้านการบริหารจัดการข้อมูลและติดตามประเมินผล
- อนุฯ 7 — ด้านความปลอดภัยทางถนนของ อปท.
- อนุฯ 8 — ด้านการรณรงค์ประชาสัมพันธ์สร้างจิตสำนึก

แต่ละหน่วยงานจะถูกมอบหมายให้รายงานเฉพาะข้อเสนอในอนุกรรมการที่เกี่ยวข้อง

## 10. ตัวเลขเปอร์เซ็นต์ความคืบหน้าในหน้าหลักคำนวณจากอะไร?

ตัวเลขสีเหลือง ("ดำเนินการแล้ว") คือสัดส่วนของหน่วยงานที่มีสถานะ "กำลังดำเนินการ" หรือ "เสร็จสิ้น" ต่อจำนวนหน่วยงานที่เกี่ยวข้องทั้งหมด (ไม่นับ "ไม่เกี่ยวข้อง")

ตัวเลขสีเขียว ("เสร็จสมบูรณ์") คือสัดส่วนของหน่วยงานที่มีสถานะ "เสร็จสิ้น" เท่านั้น

## 11. มีปัญหาในการใช้งานระบบหรือต้องการสอบถามเพิ่มเติมติดต่อได้ที่ไหน?

สามารถติดต่อได้หลายช่องทาง:

- ส่งคำถามผ่านระบบ — เข้าสู่ระบบด้วยบัญชีหน่วยงาน แล้วไปที่แถบ "ข้อความ" เพื่อส่งคำถามถึงแอดมินโดยตรง
- ทีมเลขาธิการคณะกรรมการนิรภัยทางถนนแห่งชาติ

แอดมินจะตอบกลับในระบบ และจะมีการแจ้งเตือนเมื่อมีคำตอบ
